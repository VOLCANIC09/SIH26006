# SIH26006

## Bulk Cargo Procurement & Vessel Chartering Decision Support System

### Objective

Build a decision-support system for industrial bulk-cargo procurement.

The system will:

1. Forecast freight rates
2. Estimate uncertainty
3. Simulate possible market scenarios
4. Evaluate vessel/port feasibility
5. Optimize chartering decisions
6. Quantify financial risk
7. Recommend a risk-adjusted shipping strategy

### Initial Scenario

Commodity: Coal

Origin: Australia

Destination: Paradip

Planning Horizon: 3 months
